# 🌸 Fleuré Studio

A modern floral website concept designed for a fictional flower studio.

## 🔗 Live Demo
https://clivestudio.github.io/fleure-studio/

## 📖 About
Fleuré Studio is a fictional flower shop website concept with a clean, elegant, and modern design. It showcases floral collections and provides a simple way for visitors to explore the studio.

## ✨ Features
- Responsive website design
- Modern and elegant interface
- Flower collection showcase
- Image gallery
- Smooth scrolling and reveal animations
- Contact section

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
